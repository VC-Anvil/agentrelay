# AR-0025 · Verificación local de informe y recibo

`verify_report(directory, *, receipt_sha256=None)` inspecciona únicamente `receipt.json` y `report.md` del directorio explícito. Ignora `cwd`, `artifacts_dir` y URI incluidos en el recibo; no abre DB, ejecutores, procesos ni red. Reutiliza las lecturas estables, el rechazo de enlaces/reparse y la validación de archivos regulares de `snapshots.py`; cada archivo está limitado a 1 MiB. Valida el directorio real y comprueba su identidad al terminar. El recibo se vuelve a leer después del informe para detectar cambios durante la comprobación.

El resultado distingue `unchanged`, `modified`, `missing` y `uncheckable`, con hashes esperado y observado cuando se pueden conocer. Un recibo histórico sin `report_sha256` queda `uncheckable`: no se reconstruye ni se escribe una línea base. Si se proporciona un hash previo del recibo y no coincide, el resultado es `uncheckable` y ni siquiera se lee `report.md`. Un recibo que cambia durante la lectura deja `receipt_sha256` y la comparación del ancla en `null`, pues ya no hay un único contenido estable. Igualdad con el hash del recibo sólo acredita integridad relativa de bytes, no autenticidad, calidad ni aceptación del trabajo.

El fixture de reproducción `.agentrelay/report-integrity-repro` devolvió `modified`: esperado `4da5b4f32bd1528841a54e5d402f5517d0c4c65dd2722dd44edbabf43672802f`, observado `904222b21a26199e3c1231c71adc9d997ddce52e94af4826f15b12a04cff917f`. No se modificó el piloto histórico.

`tests/test_report_integrity.py` cubre los cuatro estados, ancla, recibos ausentes/malformados/sin hash/profundos (5.000 niveles), tamaños, lectura ilegible, rutas externas ignoradas, cambios concurrentes inyectados y ausencia de escrituras. Resultado propio: 7 pruebas pasan y 1 prueba de enlaces reales queda omitida porque este Windows no permite crearlos; otra prueba con inyección de reparse valida las ramas de rechazo. `git diff --check` pasó. El sandbox rechazó `Path.resolve(strict=True)` sobre un directorio temporal legible; la implementación usa ruta absoluta y `lstat` de sus componentes, sin elevar permisos. No promete snapshot atómico ni defensa completa frente a un proceso hostil que sustituya rutas durante la verificación. El modelo/esfuerzo efectivos del host no están atestiguados y AR-0025 los declara `unknown`.
